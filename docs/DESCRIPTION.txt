DESCRIPTION OF MTG METAGAME ANALYZER
=====================================

PROJECT OVERVIEW
----------------
MTG Metagame Analyzer is a data analysis tool designed for Magic: The Gathering players, 
tournament organizers, and competitive meta researchers. It processes metagame data from
tournaments and provides comprehensive visualizations and statistical analysis at both
deck and archetype levels.

WHAT IT DOES
------------

1. DATA INPUT & PROCESSING
   - Reads deck metagame percentages and win rates from Excel files
   - Optionally loads historical data from previous weeks
   - Cleans deck names (removes special symbols like □■▪•)
   - Automatically calculates week index for new data
   - Validates and normalizes input data

2. STATISTICAL ANALYSIS
   - Calculates hypergeometric probabilities for deck encounters
   - Computes importance scores combining metagame prevalence and performance
   - Assigns quartile-based "Prep Priority" rankings
   - Categorizes decks as "Underplayed Winners" or "Popular Traps"
   - Tracks trend direction (rising/falling/stable) over time

3. ARCHETYPE AGGREGATION & HISTORY
   - Groups individual decks by archetype automatically
   - Calculates weighted averages for archetype-level metrics
   - Stores archetype data in history CSV with 'Level' column = 'Archetype'
   - Tracks both deck AND archetype trends over multiple weeks
   - Generates separate analysis and trend charts for archetypes

4. VISUALIZATION GENERATION
   - Bar charts showing encounter probabilities (rainbow color gradient)
   - Line charts tracking metagame trends over multiple weeks
   - Color-coded legend indicating prep priority levels
   - Performance labels on all visualizations (Underplayed Winner, Popular Trap, Neutral)
   - Trend status indicators (^=Rising, v=Falling, -=Stable)
   - Interactive features via mplcursors for data exploration

5. DATA EXPORT & HISTORY
   - Excel files (.xlsx) with detailed metrics at deck and archetype level
   - CSV files for historical data tracking (includes Level column)
   - PNG images of all charts (deck encounter, archetype encounter, deck trend, archetype trend)
   - Automatic ZIP packaging of results for easy download

KEY FUNCTIONS EXPLAINED
-----------------------

analyze_metagame(filename_excel, history_csv=None, total_encounter_players=1000)
PURPOSE: Main analysis function that processes current week data and historical data
INPUT:
  - filename_excel: Path to Excel file with columns Deck, Meta, Winrate, [Archetype, My Winrate]
  - history_csv: (Optional) Path to CSV with historical data from previous weeks
  - total_encounter_players: Tournament size for probability calculations (default 1000)
OUTPUT:
  - df_new: DataFrame with deck metrics for current week
  - df_history: Updated DataFrame combining past weeks + current week + archetypes
  - this_week_idx: Week number calculated from history
  - total_players: Confirmed player count
PROCESS:
  1. Load Excel file, create default columns if missing (My Winrate, Archetype)
  2. Load optional CSV history file
  3. Calculate week index (max previous week + 1)
  4. Clean deck display names (remove symbols)
  5. Calculate encounter probabilities and importance scores
  6. Assign quartiles and prep priority rankings
  7. Assign performance labels (Underplayed Winner, Popular Trap, Neutral)
  8. Add deck data to history
  9. CREATE ARCHETYPE AGGREGATION:
     - Call aggregate_by_archetype() to group decks
     - Call calculate_archetype_metrics() to compute archetype stats
     - Add 'Level' = 'Archetype' column to distinguish from deck records
     - Append archetype records to history
  10. Return combined dataset and updated history

aggregate_by_archetype(df_results)
PURPOSE: Groups deck-level data into archetypes
INPUT: DataFrame with Deck, Meta, Winrate, My Winrate columns
OUTPUT: DataFrame with one row per Archetype
LOGIC:
  - If no 'Archetype' column exists, all decks assigned to 'Rogue'
  - Sum Meta% for all decks in each archetype
  - Average Winrate weighted by deck Meta%
  - Average My Winrate weighted by deck Meta% (if available)

calculate_archetype_metrics(df_arch, total_players, sample_size=5)
PURPOSE: Calculates encounter probability, importance, and prep priority for archetypes
INPUT: DataFrame with archetype-level aggregated data
OUTPUT: Same DataFrame with added columns: Encounter Copies, Encounter Probability, 
        Importance, Quartile, Prep Priority, Performance Label
FORMULAS:
  - Encounter Copies = (total_players * Meta% / 100)
  - Encounter Probability = hypergeometric_probability(N, K, sample_size=5)
  - Importance = 0.70 * (Meta / MaxMeta) + 0.30 * ((WR - MinWR) / (MaxWR - MinWR))
  - Quartile = Q4/Q3/Q2/Q1 based on Importance percentiles (25%, 50%, 75%)
  - Performance Label = "Underplayed Winner" if Meta < median AND WR > median, etc.

create_encounter_probability_chart(df_results, week_num, N_players, chart_type="Deck", min_encounter_threshold=0.05)
PURPOSE: Generates bar chart showing encounter probabilities
INPUT: 
  - df_results: DataFrame with Encounter Probability, Prep Priority, Performance Label
  - week_num: Week number for filename
  - N_players: Tournament size (for title)
  - chart_type: "Deck" or "Archetype" (affects sorting and limits)
OUTPUT: PNG file named encounter_prob_{chart_type}_W{week_num}.png
FEATURES:
  - Sorted descending by probability
  - Optional minimum encounter probability filter (default 5%) for readability
  - Rainbow gradient coloring (reversed: strongest color = highest probability)
  - Probability % labels on bars (colored by prep priority)
  - Deck names rotated to avoid overlap
  - Legend showing prep priority colors and performance labels
  - 20x12 inch figure size for readability

create_trend_chart(df_history, df_results, weeks_back, week_num, chart_type="Deck")
PURPOSE: Generates line chart showing metagame shifts over weeks
INPUT:
  - df_history: Historical DataFrame with WeekIndex column
  - df_results: Current week DataFrame (to identify top 10 by Meta%)
  - weeks_back: Number of weeks to display (user-selected)
  - week_num: Current week number
  - chart_type: "Deck" or "Archetype"
OUTPUT: PNG file named meta_trend_{chart_type}_W{week_num}_last{weeks_back}w.png
LOGIC:
  1. Select top 10 by Meta% from df_results
  2. Filter df_history by Level (Deck vs Archetype)
  3. Limit to date range: [max_week - weeks_back + 1, max_week]
  4. Filter to selected top 10 decks/archetypes from step 1
  5. Plot line for each with marker='o'
  6. Color each line with rainbow gradient (reversed)
  7. Add trend symbol (^/v/-) to legend labels using calculate_deck_trend_status()
  8. Include legend with deck names and trend status
  9. Add reference box at bottom showing symbol meanings

KEY CALCULATIONS
----------------

ENCOUNTER PROBABILITY (Hypergeometric Distribution):
Mathematical question: "In a tournament with N players, if K players are piloting 
a specific deck, what's the probability I face at least 1 of them in my 5 matches?"

Function: hypergeometric_probability(N, K, sample_size, threshold=1)
Formula: P(X ≥ threshold) where X ~ Hypergeometric(N, K, sample_size)
         = SUM from k=threshold to min(K, sample_size) of:
           [C(K,k) × C(N-K, sample_size-k)] / C(N, sample_size)

Example: If N=1000, K=52 (5.2% piloting Boros), sample_size=5
Result: ~24% chance of facing Boros in 5 rounds

IMPORTANCE SCORE (0-1 Scale):
Hybrid metric combining metagame prevalence (70% weight) + performance (30% weight)

Formula: Importance = 0.70 × (Meta% / Max Meta%) + 0.30 × (WR - Min WR) / (Max WR - Min WR)

Interpretation:
- 0.00-0.25: Low importance (Q1) - minimal prep needed
- 0.25-0.50: Medium importance (Q2) - optional prep
- 0.50-0.75: High importance (Q3) - recommended prep
- 0.75-1.00: Very high importance (Q4) - critical prep

Example:
  Deck A: 8% Meta, 52% WR → Importance = 0.70×(8/10) + 0.30×(0.10/0.15) = 0.616 (Q3)
  Deck B: 2% Meta, 58% WR → Importance = 0.70×(2/10) + 0.30×(0.16/0.15) = 0.452 (Q2)
  → Deck A gets more prep priority despite lower WR (more prevalent)

PREP PRIORITY QUARTILES:
Based on Importance score percentiles:
- Q4 (Very High): Top 25% → Red color on charts
- Q3 (High): 25-50% → Orange color
- Q2 (Medium): 50-75% → Blue color
- Q1 (Low): Bottom 25% → Green color

PERFORMANCE LABELS:
Categorizes decks relative to median Meta% and Median Winrate:

1. UNDERPLAYED WINNER
   Condition: Meta% < Median Meta% AND Winrate > Median Winrate
   Insight: Strong deck that people are underestimating
   Action: Play it or specifically prepare to beat it
   Color: Bright yellow-green (#b9f03a)

2. POPULAR TRAP
   Condition: Meta% > Median Meta% AND Winrate < Median Winrate
   Insight: Overhyped deck that doesn't perform
   Action: Prepare to exploit these pilots
   Color: Orange (#f07431)

3. NEUTRAL
   All other combinations - deck performs as expected
   Color: Black (#000000)

TREND CALCULATION (Latest 4 Weeks):
Compares oldest vs newest data points in lookback window

Formula: Trend Change = Latest Meta% - Oldest Meta%
- Rising: Change > +0.5% for decks, > +0.2% for archetypes (^ symbol)
- Falling: Change < -0.5% for decks, < -0.2% for archetypes (v symbol)
- Stable: Change within the thresholds above (- symbol)

Example:
  Week 1: 4.2%
  Week 2: 4.5%
  Week 3: 5.1%
  Week 4: 5.9%
  → Change = 5.9 - 4.2 = 1.7% > 0.5% → RISING

INPUT REQUIREMENTS
------------------

EXCEL FILE (REQUIRED):
Must contain columns (case-sensitive):
  - "Deck": Deck name (string, any special characters allowed)
    Example: "Boros Ferocity □", "Grixis Control", "Mono-U Tempo"
  - "Meta": Metagame percentage (number)
    Range: 0.1 to 100, represents % of field
    Example: 5.2 (meaning 5.2%)
  - "Winrate": Win rate as decimal (number)
    Range: 0.0 to 1.0, can be >0.5 to indicate advantage
    Example: 0.52 (meaning 52%)

EXCEL FILE (OPTIONAL):
  - "Archetype": Deck category for grouping (string)
    Example: "Aggro", "Control", "Midrange", "Combo"
    If missing: All decks assigned to "Rogue" archetype
  - "My Winrate": Your personal win rate vs this deck (number, 0-1)
    If included: Marked with * on chart labels
    Useful for personal metagame analysis

CSV HISTORY FILE (OPTIONAL):
Same columns as Excel file, plus:
  - "WeekIndex": Week number (integer)
    Example: 1, 2, 3...
    If missing: Auto-calculated based on file order
  - "Level": (ADDED IN v1.2) "Deck" or "Archetype"
    Distinguishes between deck-level and archetype-level records
    Used to filter which records to include in trend charts

FORMAT EXAMPLE (CSV):
  Deck,Meta,Winrate,Archetype,My Winrate,WeekIndex,Level
  Boros Ferocity,5.2,0.52,Aggro,0.58,1,Deck
  Grixis Control,4.1,0.51,Control,0.45,1,Deck
  Aggro,9.3,0.51,Aggro,0.56,1,Archetype

OUTPUT FILES EXPLAINED
----------------------

1. deck_analysis_W{N}.xlsx
   - One row per DECK (not archetype)
   - All calculated metrics: Encounter Probability, Importance, Quartile, etc.
   - Ready for further analysis in Excel
   - Columns: Deck, Meta, Winrate, Archetype, My Winrate, Encounter Copies,
             Encounter Probability, Importance, Quartile, Prep Priority, 
             Performance Label, Trend Label, Pillar, Emerging Threat, Declining Threat

2. deck_analysis_ARCHETYPE_W{N}.xlsx
   - One row per ARCHETYPE (aggregated decks)
   - Archetype-level metrics and priorities
   - Same columns as deck file, but Archetype name in Deck column

3. Metagame_History_W{N}.csv
   - Combination of deck AND archetype records
   - Use as history input for next week's analysis
   - Contains Level column ('Deck' or 'Archetype') to distinguish
   - Can grow indefinitely - system dedupes current week automatically

4. encounter_prob_Deck_W{N}.png
   - Bar chart of encounter probabilities for all decks
   - X-axis: Deck names (rotated)
   - Y-axis: Probability (0-100%)
   - Colors: Rainbow gradient, reversed
   - Labels: Probability % (colored by prep priority)
   - Legend: Prep priority colors + Performance labels

5. encounter_prob_Archetype_W{N}.png
   - Bar chart of encounter probabilities for archetypes
   - Same format as deck chart, aggregated to archetypes
   - Fewer bars, higher probabilities (consolidated meta%)

6. meta_trend_Deck_W{N}_last{X}w.png
   - Line chart showing top 10 decks' meta% over last {X} weeks
   - X-axis: Week number
   - Y-axis: Meta %
   - Each deck: Different color line with marker='o'
   - Legend: Deck names with trend symbols (^/v/-)
   - Bottom note: Reference for trend symbols

7. meta_trend_Archetype_W{N}_last{X}w.png
   - Line chart showing archetype meta% over last {X} weeks
   - Same format as deck trend chart
   - Typically fewer lines (one per archetype)

WORKFLOW EXAMPLE
----------------

FIRST RUN (No History):
1. Prepare Excel file with this week's meta data
2. Upload only the Excel file to Colab
3. Enter player count (default 1000)
4. Script outputs 2 encounter charts + Excel files + CSV history
5. Download ZIP with all results

SUBSEQUENT RUNS (With History):
1. Prepare Excel file with current week's meta
2. Upload Excel file + last week's "Metagame_History_W{N}.csv"
3. Enter player count
4. Enter weeks back for trend (default 4)
5. Script outputs all 4 charts + Excel files + updated CSV
6. Next week, use the new CSV as history input

EXAMPLE DATA CYCLE:
Week 1: Input only Excel file
        → Output: Metagame_History_W1.csv (2 records per deck: Deck level + Archetype level)

Week 2: Input Excel file + Metagame_History_W1.csv
        → Script dedupes Week 2 records, adds new ones
        → Output: Metagame_History_W2.csv (4 records per unique deck: 2 from W1, 2 from W2)
        → Generates trend charts (requires 2+ weeks)

Week 3: Input Excel file + Metagame_History_W2.csv
        → Output: Metagame_History_W3.csv (6 records per unique deck)
        → Trend charts now show 3 weeks of history

COMMON CUSTOMIZATIONS
---------------------

CHANGE ENCOUNTER PROBABILITY FORMULA:
- Modify hypergeometric_probability() function
- Change sample_size parameter (currently 5 = Swiss round opponents)
- Change threshold parameter (currently 1 = at least 1 encounter)

ADJUST IMPORTANCE WEIGHTS:
- In calculate_archetype_metrics(): Change 0.70 and 0.30 coefficients
- 0.70 = weight on Meta%, 0.30 = weight on Winrate
- Can use any values that sum to 1.0

CHANGE QUARTILE BREAKPOINTS:
- In quartile_label() nested function: Modify Q1/Q2/Q3/Q4 thresholds
- Currently: q1=25th percentile, q2=50th, q3=75th
- Can use deciles (10th, 20th, etc.) instead

CUSTOMIZE COLORS:
- Modify PREP_PRIORITY_COLORS dictionary (red/orange/blue/green)
- Modify PERFORMANCE_COLORS dictionary (yellow-green/orange/black)
- Modify TREND_COLORS dictionary (rising=green/falling=red/stable=gray)
- Change colormap in create_encounter_probability_chart(): plt.cm.rainbow to other option
