# Examples - MTG Metagame Analyzer

This folder contains example input data and sample output files to help you understand the tool's functionality.

## Files

### Input Data

- **`sample_metagame_data.xlsx`** - Example input file with MTG deck metagame data
  - Required columns: `Deck`, `Meta`, `Winrate`
  - Optional columns: `Archetype`, `My Winrate`
  - Format: Each row represents one deck/strategy in the current metagame

- **`sample_history.csv`** - (Optional) Historical metagame data from previous weeks
  - Used to calculate trends and identify rising/falling strategies
  - Can be generated by previous runs of the analyzer

### Output Files

The `outputs/` folder contains sample files generated by the analyzer:

#### Charts (PNG)
- **`encounter_prob_Deck_W1.png`** - Bar chart showing encounter probability for individual decks
- **`encounter_prob_Archetype_W1.png`** - Bar chart for archetypes (aggregated data)
- **`meta_trend_Deck_W1_last4w.png`** - Line chart showing metagame trends over 4 weeks

#### Data Files (Excel)
- **`deck_analysis_W1.xlsx`** - Detailed analysis per deck including:
  - Meta percentage
  - Win rate
  - Encounter probability
  - Importance score
  - Prep priority level
  - Performance classification

- **`deck_analysis_ARCHETYPE_W1.xlsx`** - Same metrics aggregated by archetype

#### History (CSV)
- **`Metagame_History_W1.csv`** - Combined history including current week's data
  - Used as input for next week's trend analysis

## How to Use

1. **Prepare your data** - Create an Excel file with the same structure as `sample_metagame_data.xlsx`
2. **Run the analyzer** - Upload your file to Google Colab and run the script
3. **Compare with examples** - Use these output files to understand what to expect

## Data Format

### Sample Input (Excel)

| Deck | Meta | Winrate | Archetype | My Winrate |
|------|------|---------|-----------|-----------|
| Azorius Control | 8.5 | 52.3 | Control | 65.0 |
| Gruul Aggro | 12.2 | 48.9 | Aggro | 42.5 |
| Izzet Murktide | 7.3 | 51.8 | Tempo | 58.0 |

### Interpretation of Output

**Encounter Probability**: Likelihood of facing this deck in a tournament
- Calculated using hypergeometric distribution
- Based on meta percentage and sample size (default: 5-round tournament)

**Importance Score**: Combined metric (70% meta + 30% win rate)
- Used to determine prep priority quartile (Q1-Q4)
- Q4 = Very High Priority

**Performance Label**:
- **Underplayed Winner**: Low meta% but high win rate → Good target
- **Popular Trap**: High meta% but low win rate → Avoid playing
- **Neutral**: Average performance
