# Contributing to MTG Metagame Analyzer

Thank you for your interest in contributing! Here are guidelines for participation.

## How to Contribute

### Reporting Bugs

Create a GitHub issue with:
- Clear title describing the bug
- Steps to reproduce
- Expected vs actual behavior
- Your system info (OS, Python version)
- Error messages/screenshots if applicable

### Suggesting Enhancements

Open an issue with:
- Feature description
- Use case and benefits
- Example of how it would work
- Any relevant code samples

### Submitting Code

1. **Fork** the repository
2. **Create a branch**: `git checkout -b feature/your-feature-name`
3. **Make changes** following the style below
4. **Test** your code thoroughly
5. **Commit** with clear messages: `git commit -m "Add feature X"`
6. **Push** to your fork: `git push origin feature/your-feature-name`
7. **Create Pull Request** with description of changes

## Code Style

- Follow PEP 8 guidelines
- Use meaningful variable names
- Comment complex logic
- Keep functions focused and single-purpose
- Maximum line length: 100 characters

## Testing

Before submitting:
- Test with sample Excel files
- Verify all charts generate correctly
- Check error handling for invalid inputs
- Test with both small and large datasets
- Test with and without history CSV

## Documentation

- Update README.md if adding features
- Add docstrings to functions
- Include comments for complex calculations
- Explain any new color schemes or categorizations

## Pull Request Process

1. Update documentation for new features
2. Reference any related issues (#123)
3. Provide clear description of changes
4. Include sample output/screenshots if applicable

## Areas for Contribution

- Performance optimizations
- Additional chart types
- Alternative input formats (CSV, JSON)
- Localization to other languages
- Enhanced error messages
- Unit tests
- Documentation improvements

## Questions?

Open a GitHub discussion or issue. We're happy to help!

Thank you for making MTG Metagame Analyzer better!
